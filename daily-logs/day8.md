## Key Learnings
- Logistic regression models probability of binary outcome using the sigmoid function.
- The decision boundary is linear in feature space.
- Cross‑entropy loss comes from maximum likelihood estimation.
- Gradient descent update for logistic regression is identical in form to linear regression, but with a different hypothesis.
